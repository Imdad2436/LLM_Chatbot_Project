
# Local LLM Chatbot with Text Analysis

## Project Overview

This project is a local AI chatbot built using Python, Streamlit, Ollama, and the Qwen2.5 3B language model.

The chatbot supports two-way conversations and analyzes both user messages and AI-generated responses.

## Features

- Local chatbot powered by Qwen2.5 3B
- Multi-turn conversation history
- User and AI character counting
- Prompt and generated token usage reporting
- Repeated-word analysis for user messages
- Repeated-word analysis for AI responses
- Interactive Streamlit web interface

## Technologies Used

- Python
- Streamlit
- Ollama
- Qwen2.5 3B
- Python Counter and re modules

## Installation

### 1. Install Ollama

Download Ollama from:

https://ollama.com/download

### 2. Download the language model

Open Command Prompt and run:

```cmd
ollama pull qwen2.5:3b
```

### 3. Install Python dependencies

In the project folder, run:

```cmd
pip install -r requirements.txt
```

## Running the Chatbot

Start the Streamlit application:

```cmd
streamlit run app.py
```

Open the local URL shown in the terminal, usually:

http://localhost:8501

Ollama must be installed and running.

## Text Analysis

The sidebar displays:

1. Character count of the latest user message
2. Character count of the latest AI response
3. Prompt tokens processed by the model
4. Tokens generated by the model
5. Repeated words in the latest user message
6. Repeated words in the latest AI response

Prompt tokens include the conversation context sent to the model, while generated tokens represent the latest AI output.

## Testing

The application was tested for:

- Correct repeated-word counting
- Multi-turn conversation memory
- Sidebar text-analysis updates

All three tests passed.

## Model

Qwen2.5 3B is a pretrained open-source language model accessed locally through Ollama. No additional model training or fine-tuning was performed.
